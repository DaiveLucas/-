## 一、项目定位与核心价值
================================================================================

### 1.1 项目本质
这是一个「AI 辅助开发的私人审美壁纸平台」。

核心定位：内容聚合平台
- 不是自己创造内容，而是「筛选优质内容」
- 整体流程：热门壁纸网站 → 爬虫采集图片 → 保存数据库 → 网站展示 → 用户搜索/浏览/收藏

### 1.2 核心价值
这个项目最大的价值不是赚钱，而是：
1. 提升审美 —— 学会筛选高质量壁纸
2. 学会 AI 开发 —— 掌握 AI 协作编程
3. 学会产品思维 —— 理解用户需求到产品落地的全流程
4. 学会真实项目开发流程 —— 从需求分析到部署上线
5. 拥有一个属于自己的完整项目 —— 可以写进简历、可以长期迭代

### 1.3 技术栈覆盖
在这个项目中会同时接触：
- 前端开发（React/Next.js）
- UI 设计（Tailwind CSS、组件设计）
- AI 协作开发（提示词工程、代码生成）
- 数据库（SQLite → PostgreSQL）
- API 开发（RESTful 接口设计）
- 爬虫（数据采集、解析）
- 产品设计（用户需求分析、功能规划）
- 网站架构（前后端分离、部署）

## 二、视觉风格与设计语言
================================================================================

### 2.1 整体风格
**画廊风** - 极简、画廊感、大留白、低干扰、作品优先

参考产品：
- Apple 官网（极简、高级感）
- Pinterest（瀑布流布局）
- Wallhaven（专业壁纸站）
- Unsplash（高质量图片展示）
- 少数派（内容优先设计）

### 2.2 设计原则
1. UI 要弱化 —— 导航和控件不能抢眼
2. 图片才是主角 —— 图片占据视觉焦点
3. 留白要多 —— 呼吸感、高级感
4. 动效要舒服 —— 流畅、自然、不花哨
5. 页面不要花哨 —— 禁止彩虹色、高饱和装饰

### 2.3 色彩系统

【主色系】
- 主色（Primary）：#1A1A1A —— 深黑，用于文字、按钮
- 背景（Background）：#FAFAF7 —— 暖灰白，画廊感底色
- 次背景（Surface）：#FFFFFF —— 纯白，用于卡片
- 输入框背景（Surface Container）：#F5F5F0 —— 略深暖灰

【文字色系】
- 主文字（On Surface）：#151515 —— 深黑
- 次文字（On Surface Variant）：#77736B —— 暖灰，用于描述、时间

【功能色】
- 边框（Outline）：#E6E2DA —— 暖灰线条
- 成功：#22c55e
- 错误：#ef4444
- 警告：#f59e0b

【收藏色】
- 收藏激活：#E11D48（rose-600）—— 心形图标红色

### 2.4 圆角系统
- 小圆角（radius-sm）：4px —— 小元素
- 中圆角（radius-md）：6px —— 按钮
- 大圆角（radius-lg）：8px —— 卡片
- 超大圆角（radius-xl）：12px —— 搜索框
- 特大圆角（radius-2xl）：16px —— AI 搜索框

### 2.5 阴影系统
- 卡片阴影（shadow-card）：0 2px 8px rgba(0,0,0,0.06) —— 轻微浮起
- 浮动阴影（shadow-float）：0 10px 25px rgba(0,0,0,0.08) —— 弹窗、详情
- 对话框阴影（shadow-dialog）：0 25px 50px rgba(0,0,0,0.12) —— 模态框

### 2.6 字体系统
- 主字体：Inter —— 现代、清晰、专业
- 备选：system-ui, sans-serif
- 层级：
  - 页面标题：text-2xl font-bold (24px)
  - 卡片标题：text-base font-semibold (16px)
  - 正文：text-sm (14px)
  - 辅助文字：text-xs (12px)

### 2.7 间距节奏
- 元素内部紧凑：gap-1 ~ gap-2
- 区块之间拉开：gap-8 ~ gap-12
- 卡片内边距：p-4 ~ p-5
- 页面边距：px-6

## 三、页面结构与功能设计
================================================================================

### 3.1 首页（home.html）

【页面职责】
壁纸展示的核心页面，用户浏览、搜索、筛选壁纸的主要入口。

【页面结构】（从上到下）
1. 顶部毛玻璃导航栏
   - 左侧：Logo（图片图标）+ 品牌名「壁纸画廊」
   - 中间：导航链接（热门、最新、动漫、风景、治愈系）
   - 右侧：搜索按钮、深色模式切换、收藏入口
   - 效果：bg-background/80 backdrop-blur-md，滚动时保持吸顶

2. AI 搜索框区域
   - 位置：页面顶部居中，导航栏下方
   - 样式：超大圆角（rounded-2xl）、半透明背景、毛玻璃效果
   - 尺寸：max-w-2xl，高度 56px
   - 占位符：「搜索你想要的壁纸...」
   - 图标：左侧搜索图标 + 右侧 AI 闪烁图标
   - 交互：输入后回车或点击触发搜索

3. 分类标签栏
   - 标签列表：全部、热门、最新、动漫、风景、治愈系、赛博朋克、极简、太空、抽象
   - 样式：横向排列，可横向滚动（移动端）
   - 激活态：底部 primary 色下划线 + 加粗文字
   - 交互：点击切换分类，刷新下方壁纸列表

4. 瀑布流壁纸网格
   - 布局：CSS columns 实现，响应式（2/3/4列）
   - 图片数量：首屏 16 张，滚动加载更多
   - 图片来源：Unsplash 高质量图片（不同高度，自然瀑布流效果）
   - 间距：gap-4

5. 壁纸卡片（核心组件）
   - 结构：圆角图片 + 悬浮操作层
   - 交互：
     * 默认状态：仅显示图片
     * Hover 状态：scale(1.05) 放大 + 渐变遮罩 + 操作按钮浮现
     * 操作按钮：收藏（心形图标）、下载
   - 点击：跳转到详情页 wallpaper.html?id=xxx
   - 收藏状态：已收藏时心形图标变红

6. 加载更多按钮
   - 位置：底部居中
   - 样式：圆角按钮，primary 背景
   - 交互：点击加载下一页壁纸（模拟 8 张）

【交互逻辑】
- 分类切换：点击标签 → 更新激活态 → 过滤壁纸列表
- 搜索提交：输入关键词 → 回车/点击 → 跳转搜索结果（或过滤当前列表）
- 收藏操作：点击心形 → 切换收藏状态 → localStorage 同步
- 下载操作：点击下载 → 触发浏览器下载
- 主题切换：点击月亮图标 → 切换明暗主题（预留功能）

### 3.2 壁纸详情页（wallpaper.html）

【页面职责】
单张壁纸的大图预览、信息展示、操作入口、相似推荐。

【页面结构】
1. 返回按钮
   - 位置：左上角
   - 样式：圆形按钮，带左箭头图标
   - 交互：hover 时图标微移动，点击返回首页

2. 大图展示区
   - 位置：页面左侧/居中
   - 样式：max-w-4xl 限宽，rounded-2xl 圆角，shadow-float 阴影
   - 图片：展示原图（或高清缩略图）
   - 交互：点击可全屏查看（预留）

3. 信息面板（右侧）
   - 壁纸名称：如「雪山日出」
   - 分类标签：如「自然风景」
   - 标签列表：如「山脉、日出、雪景、自然、风景」（5 个标签）
   - 分辨率：如「1920 × 1080」
   - 来源：如「Unsplash」

4. 操作按钮区
   - 收藏按钮：心形图标，点击切换状态，激活时变红
   - 下载原图按钮：primary 背景，主要操作按钮

5. 相似推荐
   - 标题：「相似壁纸」
   - 布局：6 张缩略图网格（2/3/6 列响应式）
   - 卡片：圆角缩略图，hover scale(1.05)
   - 交互：点击跳转到对应壁纸详情页

【交互逻辑】
- 返回首页：跳转 home.html
- 收藏切换：更新状态 + localStorage 同步
- 下载原图：触发浏览器下载
- 相似跳转：跳转 wallpaper.html?id=xxx

### 3.3 我的收藏页（favorites.html）

【页面职责】
管理用户收藏的壁纸，批量操作入口。

【页面结构】
1. 页面标题区
   - 标题：「我的收藏」
   - 副标题：「你收藏的精选壁纸」
   - 位置：居中

2. 批量操作栏
   - 左侧：收藏数量显示，如「共 8 张」
   - 右侧：「全部下载」按钮

3. 收藏壁纸网格
   - 布局：CSS columns 瀑布流（2/3/4 列响应式）
   - 数量：预设 8 张示例壁纸
   - 卡片样式：
     * 圆角图片
     * 右上角红心收藏标记（始终显示）
     * Hover 显示渐变遮罩 + 操作按钮

4. 空态处理
   - 触发条件：收藏列表为空时
   - 内容：提示文案「暂无收藏，去首页逛逛吧」+ 跳转首页按钮
   - 位置：页面居中

【交互逻辑】
- 移除收藏：点击 → 卡片动画消失 → 更新计数 → localStorage 同步 → 空时显示空态
- 下载壁纸：点击 → 触发下载
- 全部下载：点击 → 批量触发所有壁纸下载（间隔 300ms 避免浏览器拦截）
- 卡片点击：跳转详情页

### 5.1 壁纸实体（Wallpaper）

typescript 接口定义：

interface Wallpaper {
  id: string;              // 唯一标识，如 "wallpaper-001"
  title: string;           // 壁纸名称，如 "雪山日出"
  imageUrl: string;        // 原图 URL（Unsplash/对象存储）
  thumbnailUrl: string;    // 缩略图 URL
  category: Category;      // 分类
  tags: string[];          // 标签列表，如 ["山脉", "日出", "雪景"]
  source: string;          // 来源，如 "Unsplash"
  width: number;           // 原图宽度
  height: number;          // 原图高度
  views: number;           // 浏览量（热度）
  downloads: number;       // 下载量
  createdAt: string;       // 创建时间，ISO 格式
}

type Category = 
  | 'all'        // 全部
  | 'hot'        // 热门
  | 'latest'     // 最新
  | 'anime'      // 动漫
  | 'landscape'  // 风景
  | 'healing'    // 治愈系
  | 'cyberpunk'  // 赛博朋克
  | 'minimal'    // 极简
  | 'space'      // 太空
  | 'abstract';  // 抽象

### 5.2 收藏实体（Favorite）

typescript 接口定义：

interface Favorite {
  wallpaperId: string;     // 壁纸 ID
  addedAt: string;         // 收藏时间，ISO 格式
}

## 六、技术实现方案
================================================================================

### 6.1 技术栈选型

| 层级 | 技术选型 | 选型理由 |
|------|---------|---------|
| 框架 | Next.js 16 (App Router) | AI 最擅长、主流框架、前后端一体、SSR/ISR 支持 |
| 语言 | TypeScript 5 | 类型安全、IDE 友好、减少运行时错误 |
| UI 组件 | shadcn/ui | 高质量组件、可定制、与 Tailwind 完美配合 |
| 样式 | Tailwind CSS 4 | 原型已用、utility-first、快速开发 |
| 字体 | Inter (Google Fonts) | 现代、清晰、专业、适合图片展示类网站 |
| 图标 | Lucide Icons | 开源、现代、tree-shakable、与 shadcn 配套 |
| 数据库（前期） | SQLite | 简单、无服务器、适合个人项目、上手快 |
| 数据库（后期） | PostgreSQL | 生产级、可扩展、适合部署 |
| ORM | Drizzle ORM | TypeScript-first、轻量、类型安全 |
| 爬虫 | cheerio + fetch | 轻量级、够用、易学习 |
| 图片存储 | 对象存储 (S3) | 持久化、CDN 加速、生产必需 |
| 状态管理 | React useState + localStorage | 简单、够用、收藏本地持久化 |

### 6.3 API 设计

【GET /api/wallpapers】获取壁纸列表
Query 参数：
- category?: string   // 分类筛选
- page?: number       // 分页，默认 1
- limit?: number      // 每页数量，默认 16
- search?: string     // 搜索关键词

Response：
{
  "wallpapers": Wallpaper[],
  "total": number,
  "page": number,
  "hasMore": boolean
}

【GET /api/wallpapers/[id]】获取壁纸详情
Response：
{
  "wallpaper": Wallpaper,
  "similar": Wallpaper[]  // 相似推荐
}

【GET /api/favorites】获取收藏列表
从 localStorage 读取，或从数据库查询（登录后）

【POST /api/favorites】添加收藏
Body：{ "wallpaperId": string }

【DELETE /api/favorites/[id]】移除收藏

## 七、未来 AI 功能扩展
================================================================================

### 7.1 AI 搜索（优先级：高）

【功能描述】
用户输入自然语言描述，如「治愈系雨夜动漫壁纸」，AI 自动理解关键词并推荐相关壁纸。

【实现方案】
1. 调用 AI API（如 OpenAI / Claude）解析用户输入
2. 提取关键词：治愈系、雨夜、动漫、壁纸
3. 转化为结构化查询：
   {
     "category": "anime",
     "tags": ["治愈", "雨夜", "夜晚"],
     "mood": "healing"
   }
4. 在数据库中查询匹配壁纸
5. 返回结果并展示

【技术要点】
- 需要 AI API 集成
- 需要壁纸标签体系完善
- 可以做语义搜索（embedding）

### 7.2 AI 自动标签（优先级：中）

【功能描述】
上传/采集壁纸时，AI 自动识别内容并打标签。

【实现方案】
1. 使用视觉 AI 模型（如 CLIP、BLIP）
2. 分析图片内容
3. 自动生成标签：
   - 场景：夜晚、城市、室内、自然
   - 物体：女孩、猫、车、建筑
   - 氛围：治愈、赛博朋克、极简
   - 风格：动漫、写实、抽象

### 7.3 AI 推荐系统（优先级：中）

【功能描述】
根据用户的浏览、收藏行为，自动推荐相似壁纸。

【实现方案】
1. 记录用户行为：浏览历史、收藏列表、下载记录
2. 分析用户偏好：偏好的分类、标签、风格
3. 协同过滤：找到相似用户喜欢的壁纸
4. 内容推荐：基于标签相似度推荐
5. 展示在首页「为你推荐」区域

### 7.4 AI 二创壁纸（优先级：低）

【功能描述】
基于原图，AI 风格化生成新壁纸。

【实现方案】
1. 用户选择一张壁纸
2. 选择风格：油画、水彩、赛博朋克、极简
3. 调用 AI 图像生成 API（如 Midjourney / Stable Diffusion）
4. 生成新壁纸并展示
5. 用户可以保存到收藏

## 八、爬虫数据源规划
================================================================================

### 8.1 推荐壁纸数据源

| 来源 | 特点 | 优势 | 劣势 |
|------|------|------|------|
| Unsplash | 高质量摄影图 | 免费、API 完善、质量高 | 非壁纸专用 |
| Wallhaven | 专业壁纸站 | 壁纸专用、分类完善、有 API | 需要解析 |
| Pexels | 免费图库 | 免费、质量不错 | 非壁纸专用 |
| Konachan | 动漫壁纸 | 动漫资源丰富 | 需要爬虫、有反爬 |
| Zerochan | 动漫图站 | 动漫资源多 | 需要爬虫 |

### 8.2 爬虫实现策略

【优先级策略】
1. 先用 Unsplash API（最简单、质量高）
2. 后接入 Wallhaven API（壁纸专用）
3. 最后考虑 Konachan 爬虫（动漫补充）

【爬虫流程】
1. 请求 API/网页
2. 获取图片 URL 和元数据
3. 下载图片到对象存储（可选）
4. 保存元数据到数据库
5. 定时任务更新

【数据字段提取】
- 图片 URL
- 标题
- 分类
- 标签
- 分辨率
- 来源
- 热度

### 8.3 爬虫代码示例（伪代码）

// Unsplash API
async function fetchFromUnsplash(query: string, page: number) {
  const response = await fetch(
    `https://api.unsplash.com/search/photos?query=${query}&page=${page}&per_page=30`,
    { headers: { 'Authorization': `Client-ID ${UNSPLASH_ACCESS_KEY}` } }
  );
  const data = await response.json();
  
  return data.results.map(item => ({
    id: `unsplash-${item.id}`,
    title: item.description || item.alt_description || 'Untitled',
    imageUrl: item.urls.full,
    thumbnailUrl: item.urls.small,
    category: mapToCategory(item),
    tags: item.tags.map(t => t.title),
    source: 'Unsplash',
    width: item.width,
    height: item.height,
    views: 0,
    downloads: item.downloads,
    createdAt: item.created_at,
  }));
}

## 十、注意事项与最佳实践
================================================================================

### 10.1 新手常见错误（避免）

1. ❌ 一开始做太复杂
   ✅ 先做 MVP（最小可用产品），逐步迭代

2. ❌ 疯狂学习不做项目
   ✅ 边做边学，遇到问题再学

3. ❌ 收藏太多教程
   ✅ 真正开始做，实践中学习

4. ❌ 一开始就做数据库
   ✅ 先做静态页面，数据写死，后端逻辑最后

5. ❌ UI 过度设计
   ✅ 图片为主，UI 弱化，保持简洁

### 10.2 设计原则（牢记）

1. 极简主义 —— 少即是多
2. 内容优先 —— 图片是主角
3. 留白呼吸 —— 不要填满每个角落
4. 动效舒适 —— 流畅自然，不花哨
5. 性能优化 —— 图片懒加载，首屏快速

### 10.3 代码规范

1. 使用 TypeScript 严格模式
2. 组件化思维，拆分可复用组件
3. 语义化命名，避免缩写
4. 注释适度，代码即文档
5. 错误处理完善，用户体验友好

### 10.4 性能优化要点

1. 图片懒加载（loading="lazy"）
2. 使用 WebP 格式
3. 缩略图 + 原图分离
4. CDN 加速
5. 首屏 SSR/ISR
6. 代码分割和动态导入
